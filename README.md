# Проектирование БПЛА (Вариант 8)

Этот репозиторий содержит расчётно-пояснительную записку к курсовому проекту по проектированию мультироторного БПЛА для FPV-полётов с полезной нагрузкой 200 г.

*   **Задача:** Спроектировать БПЛА с временем полёта не менее 12 минут.
*   **Сравнение:** Проведён анализ конфигураций X4 и X6.
*   **Результат:** Рекомендована конфигурация X4 как наиболее экономичная и лёгкая.

Подробности в файле `в-8`.
